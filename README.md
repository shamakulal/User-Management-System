<h3>React CRUD App</h3>
<p>A simple and elegant CRUD (Create, Read, Update, Delete) application built with React and Material-UI. It allows users to add, view, edit, and delete user information. The backend is powered by json-server for demo purposes.</p>

🧩 Features
➕ Add a new user
📋 View all users in a table
✏️ Edit existing user information
❌ Delete users from the list
🧠 Uses React Router, useState, useEffect
🎨 Styled using Material-UI components
⚡ Mock API using json-server

⚙️ Installation & Setup
Clone the repository:
git clone https://github.com/your-username/crud-app.git
cd crud-app

Install dependencies:
npm install

Start the frontend:
npm start

Start the JSON server (in a separate terminal):
npm run json-server

🧪 Available Scripts

npm start       # Runs the React app
npm run server  # Runs json-server (mock API)
npm run build   # Builds for production
npm test        # Launches test runner
