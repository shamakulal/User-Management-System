🚀 Project Title
React CRUD App
A simple and elegant CRUD (Create, Read, Update, Delete) application built with React and Material-UI. It allows users to add, view, edit, and delete user information. The backend is powered by json-server for demo purposes.

🧩 Features
➕ Add a new user
📋 View all users in a table
✏️ Edit existing user information
❌ Delete users from the list
🧠 Uses React Router, useState, useEffect
🎨 Styled using Material-UI components
⚡ Mock API using json-server

📸 Demo
https://subtle-speculoos-353c5a.netlify.app/

⚙️ Installation & Setup
cd crud-app

Install dependencies:
npm install

Start the frontend:
npm start

Start the JSON server (in a separate terminal):
npm run json-server

🧪 Available Scripts

npm start       # Runs the React app
npm run server  # Runs json-server (mock API)
npm run build   # Builds for production
npm test        # Launches test runner
